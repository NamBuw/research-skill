# Gap and research-question source readings

These are implementation notes, not instructions to install or use the listed projects. The executable checks and decision workflow are in this skill's own `scripts/storm_explorer.py`, `scripts/gap_pipeline.py`, `scripts/check_gap_record.py`, `scripts/check_gap_campaign.py`, `scripts/check_question_card.py`, `scripts/check_ai_cs_research_plan.py`, `scripts/check_engineering_diagnostics.py`, `scripts/check_experiment_manifest.py`, `gap-audit.md`, `ai-cs-gap-rq-experiment.md`, `good-question-pressure-cases.md`, and `research-workflow.md`. Local source snapshots were inspected on 2026-11-21; upstream code can change.

| Source inspected | Mechanism read | Capability implemented here | Boundary retained |
|---|---|---|---|
| [Stanford STORM / Co-STORM](https://github.com/stanford-oval/storm) (MIT) | Multi-perspective persona/question planning, deduplicated `StormInformationTable`, hierarchical `KnowledgeBase` outline, and uncovered-branch tracking. | Pure-stdlib `scripts/storm_explorer.py` (`--topic`, `--corpus`, `--out`, `--max-turns`, `--compact`) generating perspectives, Q&A turns, deduplicated table, outline, and negation-aware `uncovered_branches`. | Offline corpus exploration without live LLM generation; uncovered branches still require primary-source verification. |
| [grounded-research-ideation](https://github.com/Hopotta/grounded-research-ideation) (MIT) | Mechanical read-before-cite digest gate (`check_cites`) and dual-regime (`same` vs `cross`) search coverage tracking. | Enforced in `scripts/gap_pipeline.py` (`DROP_UNREAD_CITATION`, `DROP_INSUFFICIENT_COVERAGE`). | Digest presence checks reading registration, not semantic entailment accuracy. |
| [SGHA](https://github.com/SGHA-Research/sgha) (Apache-2.0) | 5-role critic/skeptic verification gate (`min_survival_score`, `min_critic_confidence`) and `counterevidence_linking`. | Integrated into `scripts/gap_pipeline.py` (`DROP_ARTIFICIAL_SCOPE`, `DROP_SGHA_CRITIC_REJECT`) alongside `check_gap_record.py` counterevidence checks. | Critic scores gate structural survival; human domain review remains required. |
| [CKM-HypoGen](https://github.com/TaoJinkai/ckm-hypogen) (MIT) | Temporal cutoff filtering (`published < cutoff_date`) and hindsight closure evaluation. | Integrated into `scripts/gap_pipeline.py` (`DROP_TEMPORAL_LEAK` and `hindsight_eval_date` closure). | Cutoff enforcement depends on accurate date metadata in corpus JSON. |

Zero code inspected or copied. | Local corpus kill-search only; pair with live `scripts/search_campaign.py` for field recall. |
| [ResearchRadar](https://github.com/diptiman-mohanta/ResearchRadar) (MIT) | Whole-word plural-boundary matching, author-limitation separation, and quote verification. | Integrated into `scripts/gap_pipeline.py` and `scripts/check_gap_record.py` (`--evidence-dir`). | Reviewer comments and author future-work remain leads, not open-gap proofs. |

| [research-paper-lifecycle-skills](https://github.com/shaishavmaisuria/research-paper-lifecycle-skills) (Apache-2.0) | Tolerance-aware metric comparison (`compare_metrics.py`, `verifylib.py`) and ML code completeness checklist (`audit_repo.py`). | Integrated into `scripts/check_experiment_manifest.py` (`--verify-files`, `--claims`, `--rel-tol`, `--abs-tol`, `--map`, `--audit-repo`, `--blind`, `--strict-repo`, `--compact`). | Checks on-disk hashes, numeric match, and repo structure; does not re-run training. |
| [K-Dense Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills) (MIT) | Separate target question and hypothesis, dated evidence boundary, rival explanations, and discriminating predictions. | Reflected in `scripts/check_question_card.py` and `scripts/check_ai_cs_research_plan.py`. | Structural JSON validity does not verify causal identification or source truth. |

## Adversarial cases behind the gap-record and plan checkers

The fixture and local tests specifically challenge:
- **F11 bypass closures**:
  - `scripts/check_gap_record.py`: `any(...)` -> `all(...)` on `closest_work_ids` full-text + locator evidence; `--evidence-dir` verification of claims/quotes and page/section/equation anchors across all dispositions.
  - `scripts/check_gap_campaign.py`: empty `known_seed_checks` promoted to hard error on `supported_candidate` (with canonical `rate_limited`, `bot_blocked`, `source_failed` mapping).
  - `scripts/check_ai_cs_research_plan.py`: mandatory `--campaign` and all 6 `ENGINEERING_CHECKS` enforced in `confirmatory` mode regardless of `trigger` (with exit `1` on invalid status).
  - `scripts/check_question_card.py`: placeholder `rival_explanation` rejection.
- **F19 parsimony & anti-inflation**: multi-module proposals lacking concrete `simplest_alternative`, `ablation_over_simplest_baseline`, or positive `marginal_gain`, and dramatized crisis framing over minor seed/hyperparameter noise (`DROP_PROBLEM_INFLATION`, `DROP_OVERCOMPLICATED`).
