# Retrieval and reading source study

Code-reading notes and license boundaries for the skill's built-in retrieval, citation-graph, PDF extraction, and document-grounded evidence pipeline. Snapshots were inspected in `/tmp/research-repos` on 2026-11-21; local hashes are recorded in [repository landscape](repository-landscape.md). Only Apache-2.0 / MIT-licensed patterns are adapted directly; restrictive or unlicensed repositories (`MinerU`, `Khoj`, `AI Scientist`, `Lit-Gap`) are integrated strictly via external CLI/HTTP interfaces or clean-room behavioral specifications with zero copied code.

## Verified live endpoint quirks (2026-11-21)

- **DBLP (`dblp.org/search/publ/api`)**: Can return HTTP `202` HTML Anubis challenge pages (`anubis_version`, `Making sure you're not a bot!`) instead of JSON. `scripts/search_papers.py` detects this before JSON parsing and reports `status: "bot_blocked"` (`status_category: "bot_blocked"`).
- **HuggingFace Papers**: `/api/papers?q=...` ignores `q` and returns recent papers; `/api/papers/search?q=...&limit=...` performs actual search and returns a raw JSON list (`item.paper`).
- **ACL Anthology**: `/api/search/papers/` returns HTTP `404` and `/search/?q=...` uses client-side search. Keyword queries route through Crossref `filter=prefix:10.18653` (fast, historical coverage; abstracts often omitted by depositor), while explicit `event:<id>` or `volume:<id>` queries fetch `aclanthology.org` HTML (up to 32 MB limit) with inline abstracts.
- **Crossref / OpenAlex retractions & Scite**: Crossref records retractions in `updated-by`, `update-to`, and `relation.is-retracted-by`; arXiv/DataCite `10.48550/arxiv.*` DOIs 404 on Crossref and must fall back to OpenAlex `is_retracted`. Any network failure, HTTP `429`/`5xx`, malformed JSON, or missing DOI yields `retraction_status: "unchecked"`, never `"clean"`.
