# Bundled scholar-evaluation toolkit

This directory contains the `skills/scholar-evaluation` folder from [K-Dense Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills), snapshot `ec59a29a03d5c40f73ab40878df04860bc00e876`, inspected on 2026-11-21. The upstream folder's `SKILL.md` is stored as `UPSTREAM_SKILL.md` so this package has one agent entrypoint at `research-scientist/SKILL.md`. All remaining files in `assets/`, `references/`, and `scripts/` (`_common.py`, `validate_rubric.py`, `calculate_scores.py`, `check_traceability.py`, `summarize_agreement.py`, `weight_sensitivity.py`, `check_process.py`, `generate_report_scaffold.py`) are copied without functional changes. `LICENSE.md` is the upstream repository's MIT license and copyright notice.

The root `research-scientist` skill owns the complete scoring and evaluation workflow. These bundled pure-stdlib offline scripts provide rubric validation, normalized score calculation with uncertainty intervals, evidence traceability, multi-rater agreement summaries, weight-sensitivity perturbation checks, low-stakes process gating, and report scaffolding. Hard safety boundary: they must never be used to rank people or automate hiring, tenure, grant, admissions, or editorial accept/reject decisions. Check the upstream repository before importing later updates; do not silently replace these files or delete attribution.
