# Bundled Humanizer pattern catalog

`UPSTREAM_SKILL.md` is a byte-for-byte copy of [blader/humanizer](https://github.com/blader/humanizer) `SKILL.md` at snapshot `a32f24407364c74c812b43c15926d638bee1e072`, inspected on 2026-11-21. `LICENSE.md` contains the upstream MIT license and copyright notice. The file is renamed so `research-scientist/SKILL.md` remains this package's sole agent entrypoint.

The root skill uses this catalog for a final prose-editing pass. Scientific fidelity, user-provided voice, discipline conventions, uncertainty, exact results and citations control every edit. A style pattern is a prompt to inspect wording; it does not authorize dropping a real contrast, mathematical notation, methodological qualifier, or required disclosure. The catalog is local and requires no Humanizer installation.
