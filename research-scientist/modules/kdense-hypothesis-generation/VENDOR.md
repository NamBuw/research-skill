# Bundled hypothesis-generation toolkit

This directory contains the `skills/hypothesis-generation` folder from [K-Dense Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills), snapshot `ec59a29a03d5c40f73ab40878df04860bc00e876`, inspected on 2026-11-21. The upstream folder's `SKILL.md` is stored as `UPSTREAM_SKILL.md` so this package has one agent entrypoint at `research-scientist/SKILL.md`. All remaining files in `assets/`, `references/`, and `scripts/` (`_common.py`, `validate_hypothesis_schema.py`, `check_operationalization.py`, `validate_prediction_matrix.py`, `lint_causal_claims.py`, `check_falsification_controls.py`, `audit_evidence_ledger.py`, `generate_preregistration_scaffold.py`) are copied without functional changes. `LICENSE.md` is the upstream repository's MIT license and copyright notice.

The root `research-scientist` skill owns the complete research-gap, RQ formulation, and experiment-planning workflow. These bundled pure-stdlib offline scripts provide hypothesis schema, operationalization, prediction-rival matrix, causal-claim lexical lint, falsification-control, evidence-ledger, and preregistration-scaffold checks within that workflow. They do not run live literature searches or validate empirical soundness on their own. Check the upstream repository before importing later updates; do not silently replace these files or delete attribution.
