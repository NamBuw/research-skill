# Bundled peer-review toolkit

This directory contains the `skills/peer-review` folder from [K-Dense Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skills), snapshot `ec59a29a03d5c40f73ab40878df04860bc00e876`, inspected on 2026-11-21. The upstream folder's `SKILL.md` is stored as `UPSTREAM_SKILL.md` so this package has one agent entrypoint at `research-scientist/SKILL.md`. All remaining files in `assets/`, `references/`, and `scripts/` (`_common.py`, `validate_review_intake.py`, `generate_review_scaffold.py`, `lint_review.py`, `select_reporting_guidelines.py`, `validate_claim_evidence.py`, `audit_statistics_reproducibility.py`, `audit_citations.py`) are copied without functional changes. `LICENSE.md` is the upstream repository's MIT license and copyright notice.

The root `research-scientist` skill owns the complete peer-review, scoring, and venue-evaluation workflow. These bundled pure-stdlib offline scripts provide review intake gating, review scaffold generation, review linting, reporting-guideline selection, claim-evidence matrix validation, statistical-reproducibility auditing, and Pandoc citation-key auditing within that workflow. They do not verify empirical claims against full-text papers or make editorial accept/reject decisions. Check the upstream repository before importing later updates; do not silently replace these files or delete attribution.
